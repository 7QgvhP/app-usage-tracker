# 0003. 記録は手元の SQLite に置き、外部に送らない

- ステータス: Accepted
- 日付: 2026-09-09 以前

## 背景（Context）

アプリの使用状況は、個人の行動の記録である。

## 決定内容（Decision）

記録はすべて `data/` の下（`usage.db` は SQLite）に置き、外部へは送らない。例外は、利用者が有効にした場合の Notion への日次登録だけ（既定は無効）。保持期間の上限はなく、削除する処理も入れていない。

## 理由と検討した代替案（Consequences / Alternatives）

- 記録は1年でも数MB程度に収まる。
