# 0006. 表示名の読み替えは、設定とは別の対応表で行う

- ステータス: Accepted
- 日付: 不明

## 背景（Context）

実行ファイル名やウィンドウタイトルから決まるアプリ名は、読みにくかったり、同じアプリが別々の名前で記録されたりする。

## 決定内容（Decision）

`config.json` は「名前をどう決めるか」（無視するプロセス、ブラウザのサイトの規則、実行ファイルの情報の利用）だけを持つ。決まった名前を任意の表記へ読み替え・統合するのは、`data/app_names.json`（対応表）の役目にする。

## 理由と検討した代替案（Consequences / Alternatives）

- 名前の決め方と、表示の読み替えを分けて扱える。
