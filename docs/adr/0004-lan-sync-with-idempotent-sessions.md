# 0004. スマホとの同期は LAN 内で、同じ区間を何度送っても二重にならない形にする

- ステータス: Accepted
- 日付: 2026-09-09 以前

## 背景（Context）

スマホの使用状況を PC に集めたい。スマホは PC が起動していない間も使い、OS が保持する記録は数日分しかない。

## 決定内容（Decision）

- 同じ Wi-Fi の中で、スマホから PC の同期 API へ送る（既定は無効）。外部から使えるのは同期 API だけで、共有トークンで認証する。
- スマホは区間ごとに `{パッケージ名}:{開始時刻のエポックミリ秒}` の `external_id` を振り、PC は同じ値の区間を無視する。日ごとの合計は加算せず、区間から計算し直して置き換える。
- PC が起動していない間はスマホに保存し、次に繋がったときにまとめて送る。送るものがなくても空で送り、受信がしばらくなければ警告する。

## 理由と検討した代替案（Consequences / Alternatives）

- 同じ区間を何度送っても二重に記録されないので、送り直しを気にせずに済む。
- 「届いているか」だけを見るので、スマホを使わなかった日でも誤って警告は出ない。
- 端末名 `pc` は予約語にし、PC 自身の記録を外部から上書きさせない。
